# Ansible Deployment for Just‑Auth on EC2

This directory contains Ansible automation to provision an EC2 instance (Ubuntu), install Docker and Docker Compose, and run the `just-auth` application using the existing `docker-compose.yml` and `.env` files. The frontend and backend images are pulled from private **GitHub Container Registry (GHCR)**, while PostgreSQL image comes from public **Docker Hub**.

## Prerequisites

Before using the scripts, ensure you have:

1. **AWS CLI** installed and configured with credentials that allow EC2 creation/termination.

   ```bash
   aws --version
   aws sts get-caller-identity
   aws configure list
   ```

2. **Ansible** installed on the local machine (control node)

   ```bash
   ansible --version
   ```

## Directory Structure

```text
ansible/
├── .env                        # env variables
├── docker-compose.yml          # runtime orchestration file
├── inventory.yml               # target host list (generated by setup.sh)
├── playbook.yml                # runtime provisioning file
├── README.md                   # this file
├── setup.sh                    # infrastructure setup script
└── teardown.sh                 # infrastructure teardown script
```

## The Scripts

### setup.sh

- Creates a new EC2 instance and associated resources using AWS CLI commands
- Waits for the instance to become running and passes the SSH check
- Generates the `inventory.yml` file dynamically
- Outputs the public IP of the created EC2 instance

### playbook.yml

- Installs Docker and Docker Compose on the EC2 instance
- Copies docker-compose.yml and .env files to the EC2 instance
- Logs in to GHCR inside the EC2 instance
- Starts the containers in the docker-compose.yml on the EC2 instance
- Displays the URL where the application can be accessed

### teardown.sh

- Terminates the EC2 instance and removes all related resources

## Usage

### Setup Infrastructure

```bash
cd ansible

# makes the setup.sh file executable
chmod +x setup.sh

# runs the infrastructure setup script
bash setup.sh
```

### Application Deployment

```bash
# deploy the application runtime environment
ansible-playbook -i inventory.yml playbook.yml

# browse the application at the url outputted by the playbook.
```

### Teardown Infrastructure

```bash
# makes the teardown.sh file executable
chmod +x teardown.sh

# runs the infrastructure teardown script
bash teardown.sh
```
